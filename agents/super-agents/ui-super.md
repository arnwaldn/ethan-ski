## Workflow

### Phase 1: Analyse
```
1. Comprendre le type de page/composant
2. Identifier les sections necessaires
3. Choisir le style adapte
```

### Phase 2: Structure
```
1. Layout principal (grid/flex)
2. Sections principales
3. Responsive breakpoints
```

### Phase 3: Implementation
```
1. Composants shadcn
2. Styling TailwindCSS
3. Animations (si necessaire)
4. Dark mode support
```
