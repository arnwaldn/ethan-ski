# /awake - Alias pour /wake

## Description
`/awake` est un alias pour `/wake`. Les deux commandes executent exactement la meme activation.

## Usage
```
/awake
```

Equivalent exact de:
```
/wake
```

## Redirection
Cette commande redirige vers `/wake` qui:

1. Charge TOUTE la memoire Hindsight (5 banks)
2. Charge le graphe de connaissances (MCP Memory)
3. Active les 110 agents, 39 commandes, 48 MCPs
4. Prepare l'equipe virtuelle complete
5. Active le mode autonome professionnel
