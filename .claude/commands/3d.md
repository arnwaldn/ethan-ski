# /3d Command - 3D Asset Creation

## Description
Create 3D assets, models, and scenes using Blender MCP with optional Unity integration.

## Syntax
```
/3d [mode] "[description]" [--options]
```

## Modes

### `asset` - Single Asset Creation (Default)
```
/3d asset "medieval sword with golden handle"
/3d asset "sci-fi helmet"
/3d asset "wooden treasure chest"
```

### `character` - Character Creation
```
/3d character "robot warrior"
/3d character "fantasy wizard" --style=lowpoly
/3d character "zombie enemy" --rigged
```

### `environment` - Environment/Scene
```
/3d environment "fantasy tavern interior"
/3d environment "space station corridor"
/3d environment "forest clearing"
```

### `batch` - Multiple Assets
```
/3d batch "weapon set: sword, axe, mace, shield"
/3d batch "furniture: table, 4 chairs, cabinet"
```

### `scene` - Complete Scene for Unity
```
/3d scene "game level: medieval castle courtyard"
/3d scene "VR showroom for car configurator"
```

## Options

| Option | Values | Description |
|--------|--------|-------------|
| `--style` | `realistic`, `stylized`, `lowpoly`, `cartoon` | Art style |
| `--quality` | `mobile`, `web`, `desktop`, `cinematic` | Polygon/texture budget |
| `--format` | `fbx`, `gltf`, `glb`, `obj` | Export format |
| `--target` | `unity`, `unreal`, `web`, `threejs` | Target platform |
| `--rigged` | flag | Include armature/bones |
| `--animated` | flag | Include basic animations |
| `--materials` | `pbr`, `simple`, `none` | Material type |

## Examples

### Simple Asset
```
/3d "treasure chest"
```
Result: Creates a 3D treasure chest in Blender, exports as FBX

### Game-Ready Character
```
/3d character "knight in armor" --style=stylized --rigged --target=unity
```
Result:
1. Creates stylized knight in Blender
2. Adds armature with basic rig
3. Exports FBX optimized for Unity
4. Imports into Unity project (if open)

### Web-Ready Model
```
/3d asset "product showcase stand" --quality=web --format=glb --materials=pbr
```
Result: GLTF/GLB file with Draco compression for Three.js

### Full Game Level
```
/3d scene "platformer level with floating islands" --target=unity --quality=mobile
```
Result:
1. Creates complete scene in Blender
2. Exports all assets
3. Sets up Unity scene with prefabs
4. Configures for mobile performance

### Batch Creation
```
/3d batch "RPG items: health potion, mana potion, gold coin, key, scroll"
```
Result: 5 separate assets, each exported individually

## Workflow

```
/3d "[description]"
        │
        ▼
┌───────────────────┐
│ Parse description │
│ Detect complexity │
└───────────────────┘
        │
        ▼
┌───────────────────┐
│ Blender MCP       │
│ - Create geometry │
│ - Apply materials │
│ - Set up scene    │
└───────────────────┘
        │
        ▼
┌───────────────────┐
│ Export            │
│ - FBX/GLTF/OBJ   │
│ - Textures        │
└───────────────────┘
        │
        ▼ (if --target=unity)
┌───────────────────┐
│ Unity MCP         │
│ - Import asset    │
│ - Create prefab   │
│ - Setup materials │
└───────────────────┘
```

## Output Structure

```
exports/
├── [asset-name]/
│   ├── model.fbx          # 3D model
│   ├── textures/          # Texture files
│   │   ├── diffuse.png
│   │   ├── normal.png
│   │   └── roughness.png
│   └── preview.png        # Rendered preview
```

## Integration with Other Commands

### With /game
```
/game "RPG fantasy"
→ automatically calls /3d for assets
```

### With /turbo
```
/turbo landing "3D product showcase"
→ creates Three.js scene with /3d assets
```

## Prerequisites

1. **Blender** installed and running
2. **Blender MCP Addon** installed in Blender
3. **Unity Hub** (optional, for Unity integration)
4. **Unity Project** open (optional, for auto-import)

## Setup Check
```
/3d --check
```
Verifies:
- Blender running with addon
- Unity connection (if applicable)
- Export paths configured
